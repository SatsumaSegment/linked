# linked
A doubly linked list library with generic data support.

# Operations
The library supports the following list operations:
- Initialize list (you can add your own custom destroy function for node data here, or NULL)
- Prepend
- Append
- Insert at index
- Delete head
- Delete tail
- Delete at index
- Get head
- Get tail
- Find (returns node pointer if found, else NULL)
- Get size
- Reverse list
- Concatenate list
- Print list (add a custom print function as an argument, list is looped and data is printed using your function)
- Print list backwards
- Free list

See the header file for function signatures, I didn't add doxygen stuff, sorry.
